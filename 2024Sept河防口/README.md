# Plans

## The Plan: 河防口

**前情提要**：18年时我去过一趟，是通过给村民买路钱，以进果园的名义上去的，这个机会本质上可遇不可求。河防口属于早期的长城，还不包砖，圆石直接裸露 ([2] 中有图片)。这一段有很多拦路织网的大蜘蛛。六年沧海桑田，再加上修路，很多小路已经改变，只能重新尝试。

**互联网信息**：

[1] [trip.com: 河防口長城](https://hk.trip.com/travel-guide/attraction/beijing/hefangkou-great-wall-31659639/)

* 要爬長城的話坐車坐到青龍峽，往前走兩步就是了，到河防口的不是，只是建的一個門，立了一塊碑。長城進口有兩個人收5元，沿着土路走就能開始爬長城，是修繕過的，所以也挺安全的。我們從4點上去，6點，上面風景挺高的，特別是遇到藍天白雲。如果是特地過來那倒沒必要，順路的可以過來走走。

[2] [河防口~青龙峡长城穿越](https://www.8264.com/youji/5697086.html)

* 自打疫情封控放开之后，去北京倒是方便了，但北京原来的三防人员（防疫、防火、防爬长城）仍然身兼后二职。为了赶在两防人员上岗之前顺利上山，小伙伴们也是拼了。市里队员道远的甚至凌晨3点就起床了。5点20第二集合点出发，上了高速天还是黑蒙蒙的。
* 从进山点绿篱拦网快速切上山，没有遇上防火员，长吁一口气。如果遇上本次活动极有可能泡汤，密云白道峪的那次经历让很多参加过的驴友至今还历历在目。也没有遇上当地“打劫”的，据说果园人家会以封山防火的名义收取每人10元过路费，这可不是我杜撰的，而是我查到得一篇驴记说的就是被当地人索要了每人10元过路费，虽然不多但是总感觉被讹了。
* 本次行程六只脚记录的轨迹，一个三角形的完整环穿，总体就是一升一降，起点河防口村，一路爬升到达顶点北斗峰，然后越过铁蒺藜和栅栏进入青龙峡景区的最高点玉皇顶，然后一路下降到达青龙峡道口，再沿公路迂回至起点，总长度10.85公里，历时8小时

[3] [2022-03-05 河防口长城夹扁楼鲤鱼背官地穿越](https://www.2bulu.com/community/gotohuatinfo.htm?id=eEHRgEWv1E2AwY9pCG4i1Q%3D%3D)

**计划**：
1. D-1 day：大家乘坐大巴、小火车等陆续抵达中转地
2. D day：早起，乘坐H58路前往青龙峡，H58发车时间：5:45 6:40 ... 18:50 19:40，走去公交车站需要10min。找小路上山即可。

## Plan A：响水湖

* 路线：沿大榛峪村-庄户村开车找小路上山。Route: Drive along the road from Dazhenyu Village to Zhuanghu Village and find a small path to go uphill.
